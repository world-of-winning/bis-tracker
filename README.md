# WoW BiS Tracker

> *Half the battle is knowing what to farm. The other half is RNG.*

BiS (Best in Slot) item tracker for WoW. Paste your SimC output to analyze gear, sort farming priorities, and view alt items per dungeon.

**Live:** [wowbis.gg](https://wowbis.gg)

## Features

- **SimC Import** — Paste `/simc` output to auto-analyze equipped gear
- **Farming Priority** — Stat mismatch > Alt equipped > BiS upgrade needed > Done
- **Target Tier** — Select Veteran/Champion/Hero/Mythic, sorted by ilvl gap
- **Dungeon View** — See all BiS + Alt drops per dungeon at a glance
- **Wowhead Tooltips** — In-game tooltips on item hover
- **localStorage** — Progress persists across sessions

## Local Development

```bash
bun install
bun run dev
```

## Deployment (Cloudflare Pages)

1. Push to GitHub
2. [Cloudflare Dashboard](https://dash.cloudflare.com) → Pages → Create project → Connect repo
3. Build command: `bun run build` / Output directory: `dist`

No extra config needed. Vite static build deploys as-is.

## Adding a Spec

Create a new file in `src/data/` and register it in `src/data/specs.js`.
Required data: BiS list (16 slots), Alt list, KNOWN_STATS, dungeon list.

The files in `src/data/` are generated by the scripts in `scripts/`, which run in a
fixed order — see [docs/agents/pipeline.md](docs/agents/pipeline.md).

## Data Sources

Each source is authoritative for one thing:

| What | Where from |
|---|---|
| BiS lists | Maxroll spec guides, scraped by `generate-spec-data.mjs` |
| What drops in this season's dungeons and raid | The game client's own `JournalEncounterItem`, joined through `JournalEncounter` to `JournalInstance`, served as CSV by wago.tools |
| Item names, ten locales | Wowhead tooltip API |
| Secondary stats | Wowhead tooltip markers (`rtg32` crit, `rtg36` haste, `rtg49` mastery, `rtg40` vers) |
| Stat priority | Gear observed on high-performing characters, via murlok.io — see [ADR 0001](docs/adr/0001-observed-stat-priority.md) |
| Item grade tracks and ilvl bands | Raidbots' published `bonuses.json` |
| Localized dungeon and boss names | wago.tools DB2 (`MapChallengeMode`, `JournalEncounter`, `JournalInstance`) |

Alt items are every item in the season's pool a spec can wear in a slot — see
[ADR 0002](docs/adr/0002-alt-candidates-from-drop-tables.md). Run order and
dependencies are in [docs/agents/pipeline.md](docs/agents/pipeline.md).
